## Volume landing paths

Each run writes timestamped files so Auto Loader treats every batch as new:

| Pattern | Example path |
|---------|----------------|
| `{entity}_{batch_id}.csv` | `customers_20260821T133045Z.csv` |
| `batch_id` | UTC compact stamp `YYYYMMDDTHHMMSSZ` (shared across all three files in one run) |

| Entity | Directory |
|--------|-----------|
| products | `/Volumes/de_assessment/landing/raw/products/` |
| customers | `/Volumes/de_assessment/landing/raw/customers/` |
| orders | `/Volumes/de_assessment/landing/raw/orders/incoming/` |

Optional CLI override: `--batch-id 20260821T133045Z` (same stamp for all three files).
